Study Planner

A simple web application designed to help students organize their tasks and study time.

By Fatima-Ezzohrae · 2026 · Student Project.

About the Project

Study Planner is a simple web project created to help students organize their studies and manage their daily tasks.

The application allows students to have a clear view of their tasks and organize their work more easily.

The Idea

Students often have many assignments, exercises and exams to prepare for. The idea behind Study Planner is to create a simple tool that helps them organize everything in one place.

Objective

The main objective of this project is to create a simple, clear and easy-to-use interface. The project also allows me to practice the skills I am learning in web development.

Features

  • Add a new task
  • Modify a task
  • Delete a task
  • Mark a task as completed
  • Organize tasks by priority
  • View tasks that need to be completed

Technologies Used

The project uses the following technologies:

  • HTML
  • CSS
